# IBIIIS 에셋 제작 가이드

작성일: 2026-10-01 · 버전: 0.1 · 상태: 준비용 초안

## 용도와 현재 상태

플레이어·적·오브젝트의 그림과 애니메이션을 제작하거나 도입할 때 사용하는 문서다. 현재 구체적인 수입 설정과 에셋 규격은 검증되지 않았다. 아래 미정 항목은 첫 에셋 적용 시 결정하고 실제 화면에서 확인한 뒤 기록한다.

그래픽 구성의 기준은 [게임 시스템 기획서](IBIIIS_게임시스템_기획서.md)에 있다. 3D 맵 위에 2D 스프라이트 오브젝트를 배치하는 쿼터뷰 방식이며, 돈스타브와 컬트 오브 더 램은 공간 구성의 참고다. 그림체나 픽셀 아트 사용 여부는 확정되지 않았다.

## 제작 규격 기록표

| 항목 | 현재 상태 | 결정할 내용 |
|---|---|---|
| 이미지 파일 | 플레이어 임시 적용: PNG, 알파 투명 | 정식 규격 미정(적·소품 포함). 플레이어 임시 스프라이트는 러프 스케치 |
| 해상도와 표시 크기 | 플레이어 임시: 500×500, PPU 500 = 캔버스 한 칸 너비 | 화면 확인 후 확정. 캐릭터 몸통은 캔버스의 약 60%를 차지하므로 한 칸보다 작게 보인다 |
| 기준점 | 플레이어 임시: 캔버스 아래 중앙 (Pivot 0.5, 0) | 모든 동작 스프라이트가 같은 500×500 캔버스 기준으로 제작되어야 위치가 어긋나지 않는다. 화면 확인 후 확정 |
| 방향별 그림 | 플레이어 임시: 상하좌우 4방향 + 구르기 대각 4방향 | 좌우 반전 허용 여부 미정(현재 좌·우를 별도 그림으로 사용). 정면 대기·앞뒤 대시 그림 미제작 |
| 애니메이션 | 플레이어 임시: 방향·동작별 스프라이트 교체. 이동·대시 1프레임, 구르기 2프레임 | 걷기 등 반복 애니메이션 미구현. 프레임 구성 확정 전 |
| 스프라이트 배치 | 플레이어 임시: 카메라 회전과 같은 각도로 항상 카메라를 향함 | 방향 매핑은 카메라 Y 회전 0 기준. 카메라 Y 회전을 바꾸면 방향 매핑을 다시 정해야 한다 |
| 가림과 그림자 | 임시 발밑 그림자 적용(2026-10-06): 공용 `GroundShadow` 프리팹, 캐릭터 뒤에 그림(Order in Layer -1) | 정식 그림자 그림·크기, 캐릭터끼리의 앞뒤 가림 규칙, 맵과의 깊이 관계 |
| Unity 수입 설정 | 미정 | 필터, 압축, 최대 크기, 머티리얼 |
| 이름과 저장 위치 | 미정 | 실제 폴더, 파일명, 애니메이션 이름 규칙 |

외형의 표시 크기와 격자 점유·피해 판정은 별도 개념으로 관리한다. 그림의 여백이나 크기를 바꾸는 것만으로 판정이 달라지지 않게 한다.

- 적용 프리팹과 외형 슬롯:

위 항목은 기록 양식이며, 빈 항목은 미작성 상태다. 현재 권장 해상도나 방향 수를 임의로 지정하지 않는다.

## 적용 확인 절차 — 기능 구현 후 사용

1. 실제 게임 카메라에서 발밑 위치와 한 칸 대비 크기를 확인한다.
2. 다른 캐릭터·벽·소품 앞뒤에서 가림과 그림자를 확인한다.
3. 지원하는 방향과 애니메이션 전환을 확인한다.
4. 외형 교체 전후의 이동·점유·피해 판정이 같은지 확인한다.
5. 검증된 규격을 표에 반영하고 예외가 필요한 에셋은 따로 기록한다.

프로젝트에서 교체하는 구체적인 방법은 [개발 및 사용 가이드](IBIIIS_개발_및_사용_가이드.md)에 기록한다.

## 맵 프로토타입의 임시 외형 연결 — 2026-10-02

환경 장식은 맵의 Environment Prefab에 연결하고 Scene의 해당 인스턴스에서 편집한다. 환경 프리팹 루트는 맵 (0,0) 칸 중심에 대응하며 위치·회전 0, 크기 1을 유지한다. 자식 소품은 격자 안팎에 자유롭게 이동·회전·크기 조정할 수 있다. Cell Size 변경에 따라 환경 배치를 자동 조정하지 않는다. 환경 Collider와 격자 점유는 별개다. 환경 저장·교체·미적용 변경 보호 절차는 개발 및 사용 가이드의 Scene 환경 장식 배치를 따른다. 정식 소품 스프라이트 제작 규격은 여전히 미정이다.

- 타일 에셋의 `Visual Prefab`은 선택 슬롯이다. 없으면 바닥·장애물을 색상 블록으로 표시한다. `Color`는 편집 격자와 대체 블록 색상이며 연결한 프리팹의 머티리얼은 덮어쓰지 않는다.
- 기본 셀 크기는 1 Unity 단위이고 맵은 XZ 평면에 배치한다. 논리 칸 중심에 별도 앵커를 생성하고 그 아래 프리팹을 원래 로컬 변환대로 연결한다. Cell Size를 바꿔도 프리팹 자체 크기를 자동 보정하지 않는다. 현재 한 칸 크기에 맞는 외형을 준비한다.
- 플레이어는 `Assets/IBIIIS/Settings/GlobalPlayerSettings.asset > Visual Prefab`으로 교체한다. 같은 공용 설정을 참조하는 모든 씬에 적용한다. 없으면 카메라를 향한 노란 평면 표식을 사용한다. 표식은 임시이며 정식 캐릭터 에셋·애니메이션 규격이 아니다. 2026-10-06부터 기본 설정에 `Characters/Player/PlayerVisual.prefab`(임시 스케치 스프라이트)이 연결되어 있다. 연결 방법은 개발 및 사용 가이드의 공용 플레이어 설정을 따른다.
- 논리 위치와 시각적 위치 보정은 분리한다. 외형 크기·자식 위치·Collider는 현재 격자 이동 판정에 관여하지 않는다. 이동 가능 여부는 타일의 Walkable로 관리한다.
- 테스트 씬 카메라는 공용 설정의 Perspective 정면 방향을 사용한다. 현재 값과 편집 위치는 개발 및 사용 가이드의 공용 카메라 설정을 참조한다. 출시용 세부 에셋 규격은 여전히 미정이다. 색상 블록은 `Assets/IBIIIS/Materials/PrototypeUnlit.mat`을 사용한다.
- 외형 교체 후 판정 유지 자동 테스트 통과. 접지·가림·표시 크기·실제 화면은 사용자 확인 대기이며 위 제작 규격 표의 미정 상태를 유지한다.
- Scene 미리보기와 Play는 같은 외형 생성 코드를 사용한다. 타일 외형·색상·시작 위치는 Play 전에도 확인할 수 있다. 미리보기는 저장되지 않고 재생성되므로 생성된 자식의 외형을 직접 편집하지 않는다. 카메라 자동 맞춤을 끄면 Scene에서 조정한 카메라 설정을 Play에서도 유지한다. 자세한 절차는 개발 및 사용 가이드의 Scene 확인 항목을 따른다.

## 발밑 보정·그림자·진행 방향 화살표 — 2026-10-06 (임시)

- **플레이어 발 위치**: 임시 스케치는 500×500 캔버스 아래에 그림마다 다른 투명 여백(대기 42~69px, 이동 약 45px, 구르기 31~120px)이 있어 발이 칸 중앙보다 떠 보였다. 그림을 고치지 않고 `Characters/Player/PlayerVisual.prefab`의 `PlayerVisual > Foot Offset`(칸 단위, 현재 **0.15**)으로 스프라이트를 카메라 화면 아래쪽으로 내렸다. 표시 전용이며 격자 위치·판정에는 영향이 없다. 그림마다 여백이 달라 동작에 따라 0.05칸 정도 차이는 남는다. 정식 그림은 발이 캔버스 아래 기준선에 닿게 제작하고 이 값을 0으로 되돌리는 것을 권장한다.
- **그림자**: `Characters/Shared/GroundShadow.prefab`(원형 그라데이션 `GroundShadow.png`, 크기 0.7칸)을 플레이어·적 프리팹 루트에 중첩 프리팹으로 붙였다. 바닥 위 높이 0.03, 캐릭터 뒤(Order -1)에 그린다. 크기·진하기는 공용 프리팹(Scale, Color)에서 바꾸면 모두에 적용된다.
- **적 진행 방향 화살표**: 4방향 스프라이트가 생기기 전까지 `Characters/Shared/FacingArrow.prefab`(삼각형 `FacingArrow.png`, 크기 0.42칸, 연노랑)을 적 발밑에 붙였다. 적 루트가 진행 방향으로 회전하므로 화살표가 앞을 가리킨다. 뒤를 볼 때 몸에 가려지지 않도록 캐릭터 위(Order 1)에 그린다. 이전의 가는 선 3개(`Direction` 쿼드)는 제거했다. 4방향 스프라이트를 도입하면 각 적 프리팹에서 `FacingArrow` 자식을 지우면 된다.
- **생성 도구**: 메뉴 `IBIIIS > Create Ground Markers (Shadow, Facing Arrow)`가 위 PNG·프리팹을 없을 때만 만들고, 플레이어·`Characters/Enemies`의 적 프리팹에 빠진 그림자·화살표만 붙인다. 기존 파일·자식은 덮어쓰지 않는다. 그림을 바꾸려면 PNG를 교체한다. 기본 적·플레이어 생성 메뉴도 이 도구를 함께 실행한다.
- **검증**: 컴파일 완료, EditMode 65/65 통과(발 보정이 화면 아래 방향·칸 단위로 적용되고 반복 호출에도 누적되지 않음, 모든 적 프리팹의 화살표가 4방향 각각 앞을 가리킴, 그림자·화살표 그리기 순서, 이전 방향 선 제거, 플레이어 그림자). 실제 화면의 발 위치·그림자 진하기·화살표 크기는 사용자 확인 대기다.
