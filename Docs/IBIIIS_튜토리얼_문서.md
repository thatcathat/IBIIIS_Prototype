# IBIIIS 튜토리얼 문서

작성일: 2026-10-12 · 갱신: 2026-10-13(사용자 피드백 반영) · 상태: 1·2단계 구현, 사용자 확인 대기

튜토리얼 던전 1·2단계의 진행 규칙과 구현 위치를 관리한다. 기획 원본은 「튜토리얼_1_2단계_규칙_문서.docx」와 HTML 프로토타입 2개(1단계 도입·조작 학습, 2단계 회피 학습)이며 저장소 밖에 있다. 대본 진행 시스템의 사용법은 [개발 및 사용 가이드](IBIIIS_개발_및_사용_가이드.md)의 미연시 대화창·튜토리얼 대본 진행 항목, 전투 확장 규칙은 [전투 및 적 배치 가이드](IBIIIS_전투_및_적배치_가이드.md)의 대본용 전투 확장 항목을 따른다.

## 게임 시작 흐름

타이틀(`Assets/IBIIIS/Title/Title.unity`, 빌드 씬 목록 맨 앞) → `게임 시작` 버튼 또는 Enter → 튜토리얼 1단계 → 2단계 → 클리어 기록(`tutorial`) → 미니맵(`Overworld/OverworldTest.unity`). 튜토리얼 시작 전 컷신은 예정이며 아직 없다(넣을 때 타이틀의 `Start Scene Path` 앞에 둔다).

## 공통 규칙

- 대본의 대사·지문 순서를 그대로 따른다. 스크립트에 없는 힌트 문구는 넣지 않는다(입력 대기 중에는 키 표시와 칸 점멸만 보인다).
- 대사는 클릭·Enter·Space·F로 넘긴다(기획서 검토 의견으로 F 추가). 입력이 필요한 단계에서는 안내된 입력만 받고 나머지는 무시한다. 대본이 도는 동안 되돌리기·다시 시작·범위 표시·적 인식 말풍선은 쓰지 않는다.
- 구르기는 이번 튜토리얼에 없다(허용 행동에 넣지 않음).
- 좌표: 기획서는 (열, 행)이고 행 0이 맨 위다. 맵·대본은 행 0이 맨 아래이므로 맵 행 = 맵 높이 − 1 − 기획서 행으로 옮겼다.
- 표기: 화자 이름표는 「어시파리」로 통일했다(기획서 검토 의견). 정체를 밝히기 전 줄은 「???(어시파리)」. 대사 본문의 표기("어씨파리" 등)는 대본 그대로 두었다. 대사 속 플레이어 이름은 「플레이어」(이름 기능은 나중), 화자 이름표는 대본대로 「주인공」.
- 상황별 플레이어 그림(전투 가이드)은 튜토리얼에도 같이 적용된다. 단 위험 그림(`c_danger`)은 자동으로 보이지 않고 대본의 자세 단계로만 보인다(사용자 결정, 진행기 `Script Controls Danger`). 회피(Shift+W 대시 때 c_danger_cleared → _2)·벗어남 그림은 자동으로 나오고, 패배는 자유 진행이 막으므로 나오지 않는다.
- 감정 표시: 말풍선 없이 머리 위 아이콘만 보인다(사용자 결정). ❓·❗·🔻는 노란 굵은 글자 「?」「!」「▼」, 💦는 임시 물방울 그림(`Assets/IBIIIS/Tutorial/Sprites/Sweat.png`, 코드로 그림. 정식 아이콘이 생기면 대본의 Emote 아이콘 칸만 바꾼다).
- 자세 연출(사용자 결정): 「화들짝 놀람」 c_motion_surprized_R + 펄쩍(Hop), 기본 그림으로 돌아올 때도 펄쩍(사용자 요청), 2단계 「살려줘 어씨파리!!!」 대사 뒤 c_danger + 떨림(Shake)을 첫 회피 행동(A)을 시작할 때까지 유지하고 돌아올 때도 떨림, 2단계 첫 왼쪽 회피 직후 c_danger_gone + 한숨(Sigh), 돌아올 때도 한숨, 「(으쓱대며) 나.. 재능 있을지도?」 c_danger_cleared + 으쓱(Proud), 돌아올 때도 으쓱. c_danger 외에는 다음 대사가 끝나면 원래 그림으로 돌아간다. 모든 자세가 돌아올 때 그림이 바뀔 때와 같은 움직임을 준다(사용자 결정). 움직임 종류는 임시 선택이며 대본 Pose 단계의 `움직임`·`돌아올 때 움직임`으로 바꾼다. 그림은 `Assets/IBIIIS/Characters/Player/Sprites/`(PPU 500, 기준점 아래 중앙). c_motion_surprized_L(이전 놀람 그림)은 쓰지 않는다.

## 1단계 — 도입·조작 학습

- 맵 9×5(기획서에 크기가 없어 HTML 값), 시작 (1,2). 허수아비 (7,2)는 공격하지 않고 칸만 막으며 공격 학습 안내 때 나타난다. 유도 칸 (6,2)(행 2는 뒤집어도 같다).
- 어시파리는 「재빠르게 나타나」 지문 때 나타나 플레이어 옆(화면 오른쪽 위)을 따라다닌다(기획서 검토 의견).
- 진행: 도입 대사 → 이름 짓기(입력 칸, 기본값 「파리」, 확인·Enter. 입력과 무관하게 이후 대사는 「어시 파리」) → 이동 학습(W A S D 표시, 네 방향을 모두 한 번씩 눌러야 넘어감. 누른 키는 표시에서 빠짐) → 허수아비 등장·앞 칸까지 이동 → 허수아비 칸 좌클릭(「좌클릭」 표시) → 칼이 플레이어에게서 날아가는 실패 연출(1.1초) → 대사 → 2단계로 전환.

## 2단계 — 회피 학습

- 맵 7×7, 시작 기획서 (3,6) → 맵 (3,0). Enemy003 2마리: 기획서 (1,1)↓ → (1,5)↓, (4,5)↓ → (4,1)↓. 1턴 직후 합류 2마리: (6,4)← → (6,2)←, (0,5)→ → (0,1)→(합류한 턴의 공격 판정에는 참여하지 않음).
- 진행: 전투 전 대화 → `A`(왼쪽 1칸, 1턴) → 2마리 합류 → 대사 → `Shift`+`W`(위로 대시, 2턴) → 자유 진행 → 클리어 대사 → 클리어 기록 → 미니맵.
- 자유 진행(기획서 검토 의견 반영): HTML의 자동 연출 대신 플레이어가 직접 움직인다(이동·대기·대시). 했을 때 패배하는 이동은 막고 어시파리가 「거기로 가면 위험해!」를 띄운다. 경고는 넘겨야 닫히며, 경고 중과 넘긴 순간에는 입력을 받지 않아 턴이 넘어가지 않는다(전에는 넘기는 Space가 대기로 읽혀 턴이 넘어갔다). 적이 모두 사라지면 다음 대사로 넘어간다.
- 판정: 적의 조준은 게임 규칙대로 플레이어의 행동 직전 위치 기준이다(HTML은 이동 후 위치). 기획서 경로(A → Shift+W → 대기)는 두 규칙 모두 4턴에 전멸·피격 없음으로 같다.
