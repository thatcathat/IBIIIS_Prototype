# IBIIIS 튜토리얼 문서

작성일: 2026-10-12 · 상태: 1·2단계 구현, 사용자 확인 대기

튜토리얼 던전 1·2단계의 진행 규칙과 구현 위치를 관리한다. 기획 원본은 「튜토리얼_1_2단계_규칙_문서.docx」와 HTML 프로토타입 2개(1단계 도입·조작 학습, 2단계 회피 학습)이며 저장소 밖에 있다. 대본 진행 시스템의 사용법은 [개발 및 사용 가이드](IBIIIS_개발_및_사용_가이드.md)의 미연시 대화창·튜토리얼 대본 진행 항목, 전투 확장 규칙은 [전투 및 적 배치 가이드](IBIIIS_전투_및_적배치_가이드.md)의 대본용 전투 확장 항목을 따른다.

## 게임 시작 흐름

타이틀(`Assets/IBIIIS/Title/Title.unity`, 빌드 씬 목록 맨 앞) → `게임 시작` 버튼 또는 Enter → 튜토리얼 1단계 → 2단계 → 클리어 기록(`tutorial`) → 미니맵(`Overworld/OverworldTest.unity`). 튜토리얼 시작 전 컷신은 예정이며 아직 없다(넣을 때 타이틀의 `Start Scene Path` 앞에 둔다).

## 공통 규칙

- 대본의 대사·지문 순서를 그대로 따른다. 스크립트에 없는 힌트 문구는 넣지 않는다(입력 대기 중에는 키 표시와 칸 점멸만 보인다).
- 대사는 클릭·Enter·Space·F로 넘긴다(기획서 검토 의견으로 F 추가). 입력이 필요한 단계에서는 안내된 입력만 받고 나머지는 무시한다. 대본이 도는 동안 되돌리기·다시 시작·범위 표시·적 인식 말풍선은 쓰지 않는다.
- 구르기는 이번 튜토리얼에 없다(허용 행동에 넣지 않음).
- 좌표: 기획서는 (열, 행)이고 행 0이 맨 위다. 맵·대본은 행 0이 맨 아래이므로 맵 행 = 맵 높이 − 1 − 기획서 행으로 옮겼다.
- 표기: 화자 이름표는 「어시파리」로 통일했다(기획서 검토 의견). 정체를 밝히기 전 줄은 「???(어시파리)」. 대사 본문의 표기("어씨파리" 등)는 대본 그대로 두었다. 대사 속 플레이어 이름은 「플레이어」(이름 기능은 나중), 화자 이름표는 대본대로 「주인공」.
- 감정 표시: 기획서의 ❓·❗·💦·🔻는 글꼴(Noto Sans KR)에 그림 문자가 없어 「?」「!」「;;」「▼」 글자로 표시한다(그림으로 바꿀지는 미정).

## 1단계 — 도입·조작 학습

- 맵 9×5(기획서에 크기가 없어 HTML 값), 시작 (1,2). 허수아비 (7,2)는 공격하지 않고 칸만 막으며 공격 학습 안내 때 나타난다. 유도 칸 (6,2)(행 2는 뒤집어도 같다).
- 어시파리는 「재빠르게 나타나」 지문 때 나타나 플레이어 옆(화면 오른쪽 위)을 따라다닌다(기획서 검토 의견).
- 진행: 도입 대사 → 이름 짓기(입력 칸, 기본값 「파리」, 확인·Enter. 입력과 무관하게 이후 대사는 「어시 파리」) → 이동 학습(W A S D 표시, 처음 움직인 때부터 3초) → 허수아비 등장·앞 칸까지 이동 → 허수아비 칸 좌클릭(「좌클릭」 표시) → 칼이 플레이어에게서 날아가는 실패 연출(1.1초) → 대사 → 2단계로 전환.

## 2단계 — 회피 학습

- 맵 7×7, 시작 기획서 (3,6) → 맵 (3,0). Enemy003 2마리: 기획서 (1,1)↓ → (1,5)↓, (4,5)↓ → (4,1)↓. 1턴 직후 합류 2마리: (6,4)← → (6,2)←, (0,5)→ → (0,1)→(합류한 턴의 공격 판정에는 참여하지 않음).
- 진행: 전투 전 대화 → `A`(왼쪽 1칸, 1턴) → 2마리 합류 → 대사 → `Shift`+`W`(위로 대시, 2턴) → 자유 진행 → 클리어 대사 → 클리어 기록 → 미니맵.
- 자유 진행(기획서 검토 의견 반영): HTML의 자동 연출 대신 플레이어가 직접 움직인다(이동·대기·대시). 했을 때 패배하는 이동은 막고 어시파리가 「거기로 가면 위험해!」를 1.5초 보인다. 적이 모두 사라지면 다음 대사로 넘어간다.
- 판정: 적의 조준은 게임 규칙대로 플레이어의 행동 직전 위치 기준이다(HTML은 이동 후 위치). 기획서 경로(A → Shift+W → 대기)는 두 규칙 모두 4턴에 전멸·피격 없음으로 같다.

## 구현 위치

- 대본: `Assets/IBIIIS/Tutorial/Tutorial1Script.asset`, `Tutorial2Script.asset`(TutorialScript, Inspector에서 편집).
- 맵·씬: `Assets/IBIIIS/Maps/Tutorial1/`, `Tutorial2/`(각 맵·씬. 씬의 Grid Map Player에 TutorialDirector, AssiFly·Scarecrow 오브젝트가 Actors로 연결).
- 임시 그림: `Assets/IBIIIS/Tutorial/AssiFly.png`·`Scarecrow.png`·`Sword.png`(코드로 그린 그림), 대화 인물 허수아비·Enemy_00·Enemy_01(`Assets/IBIIIS/Dialogue/Characters/`, 임시 실루엣 초상화).
- 메뉴 `IBIIIS > Create Tutorial Content`가 위 에셋·씬과 타이틀을 없을 때만 만들고 빌드 씬 목록에 없는 씬만 추가한다(타이틀은 맨 앞). 이미 있는 대본·씬은 덮어쓰지 않으므로, 생성 뒤 고친 내용은 보존된다.

## 확인 상태

- 개발 검증(2026-10-12): EditMode 162/162 통과. 실제 대본·맵으로 1단계(어시파리·허수아비 등장, 허수아비 칸 막힘, 앞 칸에서 공격, 2단계로 전환)와 2단계(합류, 전멸, 클리어 기록, 미니맵 복귀)를 처음부터 끝까지 진행, 타이틀·두 씬의 연결을 확인했다.
- 사용자 확인 대기: 타이틀 → 1단계 → 2단계 → 미니맵 전체 흐름, 대사 넘김·키 표시·칸 점멸, 이름 입력, 칼 날아가는 연출, 어시파리가 따라다니는 위치, 자유 진행의 경고, 대화창 초상화(임시).

## 미정·확인 필요

- 2단계 자유 진행 뒤 지문 「주인공이 회피 후 … 몬스터끼리 부딪혀서 꽈당 사라진다」와 마지막 지문 「플레이어가 나머지 몬스터를 처리한다」는 대본 그대로 두었다. 자유 진행으로 바꾸면서 이미 일어난 일을 설명하게 되므로 문구를 바꿀지 결정이 필요하다.
- 1단계의 팝업 설명 지문(「화면 앞 팝업창으로 … 가 뜬다」)도 대본 그대로 이름 입력 전에 보인다. 뺄지 결정이 필요하다.
- 플레이어 이름 처리, 1단계 허수아비·어시파리 외형, 정식 초상화, 시작 전 컷신, 2단계 이후(05 시작 안내)는 미정이다.
