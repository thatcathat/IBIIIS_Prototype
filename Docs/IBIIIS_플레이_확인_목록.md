# IBIIIS 플레이 확인 목록

작성일: 2026-10-13 · 상태: 사용자 확인 대기 항목 모음

사용자가 직접 플레이·조작해서 확인할 항목을 한곳에 모은 목록이다. 개발 검증(컴파일·자동 테스트·코드로 진행한 확인)은 각 기능 문서에 있고, 여기에는 사람이 화면을 보고 손으로 조작해야 알 수 있는 것만 둔다. 각 기능 문서는 확인 절차를 따로 적지 않고 이 목록의 항목 ID를 가리킨다.

## 쓰는 법

- 항목 ID와 결과를 알려 주면(예: "G-03 ✅, B-06 ❌ 발이 떠 보임") 에이전트가 아래 표의 상태와 맨 아래 확인 결과 기록, 해당 기능 문서의 상태를 함께 고친다. 표에 직접 적어도 된다.
- 상태: ⏳ 대기 · ✅ 확인 · ❌ 문제 있음(메모에 내용) · ⚪ 해당 없음(기능이 바뀜) · 🔒 구현 전(아직 확인할 수 없음, 구현하면 조작을 채우고 ⏳로 바꿈)
- 조작 순서는 기능 문서에서 그대로 옮겼다. 기대와 다르면 ❌로 알려 준다. 느낌(크기·속도·강도)처럼 정답이 없는 항목은 "좋음/조정 필요"로 알려 주면 된다.
- 새 기능을 만들면 플레이로 확인할 항목을 이 목록에 추가하고, 기능 문서에는 ID만 적는다.
